# Toponymic regionalization

Can place names alone recover a city's neighbourhoods? Aggregate Overture Places to H3
cells, describe each cell by its place-name vocabulary, and run contiguity-constrained
clustering on those vectors. Four cities with published neighbourhood polygons as ground
truth: San Francisco, Toronto, Vancouver, Chicago. Related to `cadmus` (naming) and
`regionalization-lab` (methods). See `HANDOFF.md`.
